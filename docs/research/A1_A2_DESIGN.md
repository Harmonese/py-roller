# A1 / A2 固定缓存消融

状态：2026-10-15 已按用户要求回退 A1/A2 引擎代码、命令行开关及专用测试。以下为历史实验设计，不代表当前可调用接口；实验结果保留。

两项改动独立开关，默认均关闭。命令行 `--a1`、`--a2` 可单独或共同启用；Python 使用 `AlignmentSettings(evidence_scoring=True, joint_windows=True)`。实验要求 weighted / robust，CTC 定时保持 legacy。

## A1：观察支持收益

原分数为 `max(歌词词数, 观察词数) - 2*编辑代价 - 0.5`。A1 改为 `得到对应支持的观察词数 - 2*编辑代价 - 0.5`。支持要求对应操作同时消耗歌词和观察、原始对应代价小于1；每个观察词最多计一次。删除歌词词、多余观察词和完全不相关替代不获得覆盖收益。

候选检索、最小编辑对应、0.72相似度门限及小词代价不变，只改变候选排序与组合收益。A1不是已校准概率模型，也不声称最小编辑对应就是新目标下的最优对应；此轮有意固定对应算法，隔离“凭空增加长度收益”的影响。

## A2：保留多个窗口历史，联合选择歌词

每个原始窗口独立检索候选，保留每个词的窗口编号和源索引。交接位置来自已有歌词边界、转录段落边界、对应词位置以及完整保留前/后窗口的可能边界。候选分数不跨窗口累加投票。

对每份合法交接历史，投影保留完整来源跨度的候选，并在交接两侧重新发现跨窗整句。跨窗检索局限于歌词库存允许的最大词跨度。候选内部的词对应索引随投影同步移动，CTC收到的是最终获胜路径对应的词流。

每份词流用同一歌词动态规划评分；不同窗口历史暂时共存，后续词可以推翻先前最高分历史。最多保留现有 `alternatives=3` 份历史；相同活跃词后缀的历史只保留最高分者。这是近似状态合并，并非包含全部路径边界分数的精确等价状态证明，可能与束宽一起造成搜索损失。固定预算不随歌曲变化，并输出每窗提案、合并、剪枝数量和获胜来源路径。预览只处理已经收到的窗口。

合法交接要求左右词时间不倒退，同一次对应词不能从两边重复保留。未知词不强行匹配歌词，同分优先保留已有前缀。模型时间扭曲和重复词对应错误仍可能使兼容性判断错误；该实现是有预算的束搜索，不是精确无限图搜索，也没有声称能解决所有转录歧义。

## 对照与验收

`scripts/validate_a1_a2.py`读取上轮22份原声/人声缓存，运行baseline、A1、A2、A1+A2，共88次。不加载神经模型，不传入参考时间或演唱顺序。baseline与历史结果逐行核对文本、起止时间完全一致。

既统计严格身份缺失和大于0.5秒的偏差，也独立追踪原声54、人声53个第二类失败。恢复位置须在参考起点2秒内，超出者不算近位恢复。另列新缺失、原本2秒内实例丢失、多出实例以及逐首计算耗时。参考分行及跨实例错配的既有局限仍存在，数量变化不能直接当人工确认正确率。

结构测试覆盖缺失词不能增加收益、实际唱出的长版本、核心窗之前的歌词保留、重复窗口去重、真正重复保留、未知词保留、词来源投影、空窗与长空档，以及第三窗口补全整句后推翻第二窗口的选择。

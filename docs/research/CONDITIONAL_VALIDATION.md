# 条件定时实验与 Whisper 上下文调查

本轮完成CTC条件定时实现、三首六视图固定配置验证、参考位置事后路径诊断。Whisper仅查官方源码/讨论/研究及本地缓存，没有修改提示机制或重跑神经模型。默认仍为P1 robust + legacy定时、无提示。

## CTC：改变问题定义后的四组对照

新 `conditional` 模式固定P1选中的文本身份与次数，不再要求歌词路径胜过全部未知音频。每个可行连通区选一条覆盖所有选中实例的非重叠完整路径；没有完整链则该区保留粗时间。背景差值仍用于统一计分基准，但对于覆盖相同实例集合的方案，各实例背景项是常数，不能再触发“收益为负则弃权”。

固定比较：稀疏候选（原5个偏移、每偏移无约束/粗起点两条）；按1秒起点区间保留候选；在此基础上再按2秒句尾区间保留候选。所有区间由粗时间和固定预算生成，人工时间不进入推理。句尾区间覆盖粗结束前后4秒，原无句尾限制解释也保留。字符内核新增最终字符结束帧约束，穷举验证了其评分和合法性。

## 根因证据

仅撤掉未知音频门槛时，稀疏路径经常无法同时安置所有句子，146个实例回退。增加起点候选使全部实例有完整链，却把错误起点传播到相邻实例。问题不止弃权，也不是简单“正确起点没被搜索”。

事后用归一化文本和8秒范围作唯一实例关联，共147项；它只作诊断，存在重复实例关联不确定性，正式准确度仍为2秒配对。145项已保留参考起点±0.5秒的路径，2项在该范围内有路径但未保留。76项的局部最佳候选比参考约束路径高超过2个分数单位。注意：只限制起点，并不能证明整句字符和邻句占用都正确。

关键实例：

- Within原声约97.65秒：正确附近97.193秒路径已是单句最佳，但句尾伸到101.653秒，和下一句竞争。增加句尾候选后，可保留97.193–98.853秒的解释，恢复正确附近起点。这验证了“先独立选最佳句尾，再联合竞争”会丢掉关键解释。
- Blossom人声182.33秒：参考附近路径182.493秒确实存在；它虽不是单句最高分，起止联合组合最终选中了它，恢复达标。
- Fly原声126.68秒：正确附近126.893秒路径存在，但局部最优比它高约11.98分；起止版最终仍选123.593秒，说明起止候选补齐并未解决所有评分偏好。
- Fly人声196.64秒：参考附近197.013秒路径在单句上最优，但其结束位置与其他实例竞争；起止版仍输出198.933秒。本轮没有证明通过简单扩大句尾候选就能修复它。

因此根因至少有两层：候选压缩必须保留起点与句尾的联合解释；即使候选更完整，同一声学模型仍可能偏好错误位置，软时间先验与背景评分也没有校准。本轮不能据此宣布正确率上限，也不能说145项都可自动恢复。

## 边界与成本

实现依然是有限候选近似，不是全字符图的精确联合解。每实例音频≤32秒，偏移5个，起点1秒网格、句尾2秒网格，超预算回退；重叠证据范围组成连通区，连通区可能较长，目前未引入新的跨区状态切分。没有声称边界歧义已经完美处理。

缓存算法耗时合计：基线3.590秒、稀疏3.913秒、起点5.956秒、起止17.430秒。起止版约4.85倍基线，明显不满足之前25%目标。模型推理新增0秒。起止网格是诊断性结构对照，不适合作为当前性能结论；后续若继续该方向，应研究同一次DP保留起止Pareto候选，而不是反复运行强制对齐或逐曲扫描参数。

64项当前测试、75项历史实验测试通过，含负分完整链、次优路径释放邻句、远处实例稳定性、预算回退、句尾约束穷举及既有CTC回归。各视图检查输出顺序、时间范围、接受路径不重用声音。既有默认输出没有在本轮更换。

## Whisper调查结论

详细来源与证据见 [Whisper上下文审计](WHISPER_CONTEXT_AUDIT.md)。用户关于提示使用方式的怀疑有依据，但不能说已经证明某一种格式必然正确：

- `initial_prompt`是前文条件；完整、排序未确认的歌词清单会同时影响生成文字和分段，不只是词汇纠错。
- 当前版本同字符串换成`hotwords`，47个实际提示的首轮输入token完全相同；只改参数名无效。
- Within失败窗口的提示仅31个token，输出远未达到224-token预算；原始Whisper输出已将多段压缩成一段，故不是CTC或拼接首先造成的遗漏。
- 时间戳会影响内部音频推进，但缺少完整decoder/seek日志，暂不能断言漏句全部源于推进错误。
- 接下来最小实验应对少量固定窗口比较无提示、整句提示、短词汇提示，并记录原始token与seek；不要再直接整曲替换观测，也不要同时改VAD/模型/窗口长度。

- 模型路径：运行时只读取显式路径或 `<cache-dir>/models/<kind>/<revision>`，旧目录不再抢占自定义缓存。
- 模型安装：固定版本，暂存目录完成后原子发布；下载、迁移、清理使用互斥锁。

- 研究配置：继承正式运行配置，去掉重复默认值及校验。
- 回归检查：缺少数据或不足十组时失败，不能空跑成功。

## 仍需跟进的工程事项

1. 本机 Python 3.12 的 SSL 扩展缺少 Homebrew OpenSSL 动态库。离线推理可用，在线下载会受阻；属于主机环境问题，本轮没有修改系统安装。doctor 已明确报告。
2. 依赖尚未建立逐平台锁定与完整神经运行矩阵；当前 CI 主要覆盖算法和协议，不能证明每种 Torch/torchaudio、系统及设备组合都能运行。
3. 模型管理锁与分离锁在 SIGKILL 后需确认进程退出再人工清理；目前没有跨进程任务租约，也没有自动回收策略。模型删除不能与运行中的推理并发。
4. 没有按容量自动淘汰音频证据。当前磁盘占用主要是有用实验数据，自动删除会损害回归可复现性，应独立设计证据保留策略。
